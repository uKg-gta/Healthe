# GymLog prototype

Personal fitness, nutrition and health tracker built with plain HTML, CSS and vanilla JavaScript.

## GitHub Pages
Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save. Wait for deployment and open the published URL on your phone.

## Features in this prototype
- Home, Workouts, Nutrition, Progress and Profile sections.
- Off-white / forest-green design and manual light/dark switch.
- Configurable weekday schedule and exercise library.
- Workout logging: exercise, equipment, sets, reps, weight and kg/lb.
- Workout history search and weekday filter.
- Manual food logging, reusable food profiles and nutrient targets.
- Calories, protein, carbs, fats, fibre, sugar, sodium and micronutrient notes.
- Weight records, BMI calculation, basic charts and exercise load records.
- Water, sleep and steps check-in.
- Local progress photo journal.
- JSON backup export and import.

## Data storage
Records use browser localStorage and remain in this browser on this device. There is no backend or cross-device sync. Clearing browser data can remove records; export backups regularly. Photos are stored locally and may use substantial storage.

## Known prototype gaps
Full calendar navigation, same-weekday workout comparisons, detailed micronutrient analysis, BMI trend charts and richer analytics are still to be built. No reminders or separate app lock are included. GitHub Pages needs internet to load the hosted app; offline operation is not a priority.
